# Лабораторная работа 5 — «Список товаров с фильтрами»

Каталог товаров на React + Vite. Данные грузятся с https://fakestoreapi.com/products.

## Что реализовано

- Загрузка товаров через `fetch` в `useEffect` с `AbortController` (отмена запроса при размонтировании).
- Состояния: загрузка, ошибка, список товаров, отфильтрованный список, фильтры.
- Проверка `res.ok` — ответы 404/500 показываются как ошибка.
- Фильтрация на клиенте по категории и диапазону цены (второй `useEffect`).
- Валидация цены по кнопке «Применить»: отрицательная цена, «от» больше «до».
- Заглушка картинки товара через Data URI (SVG).
- Доп. задание 1: выбор нескольких категорий (массив в `useState`, чекбоксы).
- Доп. задание 2: ползунки (range) для минимальной и максимальной цены, синхронизированы с полями ввода.

## Структура

```
src/
├── App.jsx
├── main.jsx
├── index.css
└── components/
    ├── ProductList.jsx   — контейнер: загрузка, состояние, фильтрация
    ├── ProductCard.jsx   — карточка товара (только отображение)
    └── Filters.jsx       — фильтры и валидация
```

## Запуск

```

```
